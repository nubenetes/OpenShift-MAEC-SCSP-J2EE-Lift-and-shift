# Controlador JDBC Microsoft SQL Server

En un despliegue real, debes descargar el controlador oficial compatible con Java 8:
- Archivo: `mssql-jdbc-8.4.1.jre8.jar`
- Fabricante: Microsoft Corporation
- Proveedor de licencias: Microsoft JDBC Driver for SQL Server

Para pruebas de integración simuladas locales, puedes situar cualquier archivo jar con ese nombre en este directorio.
